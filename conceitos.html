Conceitos de POO

POO organiza o programa em objetos que representam coisas do mundo real, com dados e comportamentos.

ConceitoIdeiaExemplo
ClasseMolde do objetoclass Carro
ObjetoInstância da classenew Carro()
PropriedadeDados do objetoCor, Placa
MétodoAção do objetoAcelerar()
ConstrutorPrepara o objeto ao criarpublic Carro(string cor)

PolimorfismoMesmo método, comportamentos diferentesvirtual/override

Exemplo mínimo

public class Cachorro
{
    // Propriedade: o dado do objeto
    public string Nome { get; set; }

    // Método: o comportamento do objeto
    public void Latir()
    {
        MessageBox.Show(Nome + " diz: Au au!");
    }
}

// Uso (por exemplo, dentro do clique de um botão):
Cachorro c = new Cachorro();  // cria o objeto
c.Nome = "Rex";               // altera a propriedade
c.Latir();                    // chama o método
