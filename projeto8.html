Projeto 8 · Agenda de Contatos

Objetivo: criar uma classe repositório que gerencia a lista e faz buscas.

Tela

txtNome, txtTelefone, txtBusca, btnSalvar, btnRemover, dgvContatos.

Classes

public class Contato
{
    public string Nome { get; set; }
    public string Telefone { get; set; }
}

// Esta classe cuida SÓ do armazenamento e da busca.
// O formulário cuida SÓ da tela. Cada classe, uma responsabilidade.
public class AgendaRepositorio
{
    private List<Contato> contatos = new List<Contato>();

    public void Adicionar(Contato c) => contatos.Add(c);
    public void Remover(Contato c)   => contatos.Remove(c);

    public List<Contato> Buscar(string termo)
    {
        // LINQ: consulta a lista de forma declarativa.
        // Where filtra; OrderBy ordena; ToList materializa o resultado.
        return contatos
            .Where(c => c.Nome.ToLower().Contains(termo.ToLower()))
            .OrderBy(c => c.Nome)
            .ToList();
    }
}

Formulário

AgendaRepositorio agenda = new AgendaRepositorio();

private void btnSalvar_Click(object sender, EventArgs e)
{
    agenda.Adicionar(new Contato { Nome = txtNome.Text, Telefone = txtTelefone.Text });
    Mostrar("");   // "" traz todos, pois todo texto contém ""
}

// TextChanged dispara a cada letra digitada: busca em tempo real!
private void txtBusca_TextChanged(object sender, EventArgs e)
{
    Mostrar(txtBusca.Text);
}

private void Mostrar(string termo)
{
    dgvContatos.DataSource = agenda.Buscar(termo);
}
💡 Precisa de using System.Linq;. O formulário não sabe como a busca funciona, só pede o resultado.
🏆 Desafio: Impeça nomes duplicados e implemente o botão “Remover” usando a linha selecionada.
