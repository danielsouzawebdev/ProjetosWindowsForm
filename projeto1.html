Projeto 1 · Cadastro de Pessoa

Objetivo: criar a classe Pessoa e usá-la em um formulário.

Crie o projeto

Novo projeto → Aplicativo do Windows Forms → CadastroPessoa.

Monte a tela

Na Toolbox, arraste para o formulário 2 Label, 2 TextBox, 1 Button e mais 1 Label. Na janela Propriedades: Labels → Text = “Nome:” e “Idade:”; TextBoxes → Name = txtNome e txtIdade; Button → Name = btnCadastrar, Text = “Cadastrar”; Label de resultado → Name = lblResultado, Text vazio. Dúvidas? Veja o guia de Windows Forms.

Crie a classe Pessoa.cs

// Uma CLASSE é o molde: define quais dados e ações todo objeto "Pessoa" terá.
public class Pessoa
{
    // PROPRIEDADES: guardam os dados do objeto.
    // { get; set; } permite ler (get) e alterar (set) o valor.
    public string Nome { get; set; }
    public int Idade { get; set; }

    // CONSTRUTOR: método especial, tem o mesmo nome da classe.
    // Roda automaticamente quando fazemos "new Pessoa(...)".
    public Pessoa(string nome, int idade)
    {
        Nome = nome;   // guarda o valor recebido na propriedade
        Idade = idade;
    }

    // MÉTODO: uma ação do objeto. Aqui ele devolve (return) um texto.
    public string Apresentar()
    {
        // $"..." é interpolação: coloca variáveis dentro do texto com { }.
        return $"Olá, eu sou {Nome} e tenho {Idade} anos.";
    }
}

Programe o botão

private void btnCadastrar_Click(object sender, EventArgs e)
{
    // Tudo que vem de um TextBox é texto (string); convertemos para número.
    int idade = int.Parse(txtIdade.Text);

    // "new" cria o OBJETO a partir da classe, chamando o construtor.
    Pessoa p = new Pessoa(txtNome.Text, idade);

    // Chamamos o método do objeto e mostramos o retorno na tela.
    lblResultado.Text = p.Apresentar();
}

Teste

Pressione F5. Digite letras na idade: o programa quebra! Isso será resolvido no Projeto 2.

💡 Classe = molde; objeto = item criado com new. Você pode criar vários objetos da mesma classe.
