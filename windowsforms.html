Windows Forms passo a passo

Antes dos projetos, aprenda a trabalhar com o designer do Visual Studio. Siga na ordem, com o Visual Studio aberto.

Instale e abra o Visual Studio

Use o Visual Studio Community. No instalador, marque Desenvolvimento para desktop com .NET.

Crie o projeto

Tela inicial → Criar um projeto → pesquise Aplicativo do Windows Forms (C#) → Avançar. Dê um nome sem espaços (ex.: CadastroPessoa), escolha a pasta e clique em Criar.

Conheça as janelas

  • Designer (centro): o formulário visual, o Form1.
  • Caixa de Ferramentas (esquerda): os controles. Se não aparecer: menu Exibir → Caixa de Ferramentas.
  • Propriedades (direita, embaixo): aparência e nome do controle selecionado. Atalho: F4.
  • Gerenciador de Soluções (direita, em cima): arquivos do projeto.

Adicione controles

Arraste um controle da Toolbox até o formulário (ou dê clique duplo nele). Para mover, arraste; para redimensionar, use as alças. As linhas guia azuis ajudam a alinhar.

Ajuste Name e Text

Selecione o controle e abra a janela Propriedades. Text é o que o usuário vê. Name é como o controle é chamado no código. Troque o Name antes de criar eventos, senão o método fica com o nome antigo.

Use prefixos nos nomes

Isso deixa o código legível: txtNome é claramente uma caixa de texto. Veja a tabela de prefixos mais abaixo nesta página.

Crie um evento

Dê clique duplo no botão. O Visual Studio abre o código e cria o método btnCadastrar_Click. Escreva seu código entre as chaves { }. Para outros eventos (ex.: TextChanged), selecione o controle, clique no ícone de raio ⚡ na janela Propriedades e dê clique duplo no evento desejado.

Entenda os arquivos

  • Form1.cs: o seu código (eventos e lógica). Alterne com F7 (código) e Shift+F7 (designer).
  • Form1.Designer.cs: gerado automaticamente. Não edite.
  • Program.cs: ponto de partida do programa.

Adicione uma classe

Gerenciador de Soluções → clique direito no projeto → Adicionar → Classe → digite o nome (ex.: Pessoa.cs) → Adicionar. Escreva a classe e use-a no formulário.

Execute e teste

Pressione F5 (ou o botão ▶ Iniciar). Para parar, feche a janela ou use Shift+F5. Se aparecer erro de compilação, leia a janela Lista de Erros e dê clique duplo na mensagem para ir até a linha.

Primeiro teste rápido

Para treinar: coloque um Button (btnOla) e um TextBox (txtNome); no clique do botão escreva:

private void btnOla_Click(object sender, EventArgs e)
{
    // txtNome.Text é o texto digitado pelo usuário.
    // MessageBox.Show exibe uma janelinha de aviso.
    MessageBox.Show("Olá, " + txtNome.Text + "!");
}

Erros comuns

  • Apaguei um botão e deu erro: o método do evento continua no código. Apague o método também.
  • Renomeei o controle e quebrou: use o menu de clique direito → Renomear (ou Ctrl+R, R) no código para atualizar todas as referências.
  • O botão não faz nada: o evento não está ligado. Dê clique duplo de novo no botão no designer.
  • Digitei letras e o programa fechou: use TryParse (Projeto 2).
